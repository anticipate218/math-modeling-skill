# 提交前自检清单

用法：先跑 `python scripts/check_paper.py <论文> --contest <cumcm|yjs|mcm>` 做机械检查，再逐项人工确认下面的清单。
**红线项（标 🔴）任一不满足，可能直接失去评奖资格，务必优先确认。**

> 竞赛规则逐年修订。本清单依据 2026 年可获取的最新官方文件；**参赛前请重新核对当年官方通知**（链接见 `references/contests.md`）。

---

## 一、通用清单（三个竞赛都要过）

### 内容质量
- [ ] 每一问都有明确的模型、求解结果与检验
- [ ] 结论都有数字支撑（不是"效果良好""比较合理"）
- [ ] 至少有一个基线/对比方案，并说明为什么更好
- [ ] 做了灵敏度或稳健性分析，并给出具体结论
- [ ] 假设逐条在建模中被使用，且有依据
- [ ] 符号说明完整，全文符号唯一、单位统一
- [ ] 模型评价写了优点与局限（局限不写成自我否定）
- [ ] 结论没有超出模型适用范围
- [ ] 数据来源与预处理过程写清楚（外部数据必须给来源）
- [ ] 无抄袭：引用他人成果均已标注
- [ ] 对应官方评奖四维自评：假设合理性 / 建模创造性 / 结果正确性 / 文字表述清晰度（见 `references/scoring-rubric.md`）
- [ ] 官方五大内容块齐全：假设、建立与求解、**计算方法与计算机实现**、结果分析与检验、**模型改进**

### 写作与排版
- [ ] 摘要包含每一问的"方法 + 结果 + 检验"，含具体数值
- [ ] 摘要与正文的问号顺序、数值、结论完全一致
- [ ] 有技术路线图
- [ ] 图表编号连续、每张图表都在正文被引用并解释
- [ ] 图题在下、表题在上；坐标轴有量名与单位；≥300 dpi
- [ ] 公式有编号，变量含义已说明
- [ ] 参考文献格式统一，正文有对应标注
- [ ] 全文术语统一，无口语化表达
- [ ] 通读一遍无错别字（尤其标题、摘要、图表标题）

### 可复现性
- [ ] 附录包含全部可运行源程序（含 Excel/SPSS 等交互命令）
- [ ] 代码能在干净环境按论文所述步骤重跑
- [ ] 程序运行结果与论文中的数字一致（**这是最常见的致命不一致**）
- [ ] 固定了随机种子；随机算法给了多次运行统计量
- [ ] 标注了软件与依赖版本

---

## 二、AI 合规（三个竞赛都已出台规定，最容易忽略）

- [ ] 🔴 已知悉并遵守当年各竞赛的 AI 使用规定（国赛 2026 试行 / 研赛 2025 / COMAP 政策）
- [ ] 🔴 **国赛、研赛：在参考文献之前设置「AI工具使用声明」**；未使用 AI 也要声明「本参赛队在竞赛过程中未使用任何AI工具。」
- [ ] 🔴 使用了 AI 的：**支撑材料中含 `AI工具使用详情.pdf`**，写明工具名称与版本、使用目的与环节、主要提示方式与交互示例、对输出的采纳与人工核验情况（语言润色除外）
- [ ] 🔴 无隐瞒、无虚假声明（国赛规定：隐瞒或虚假声明 → 取消评奖资格）
- [ ] 研赛：程序开头加注释说明「本程序及代码是在人工智能工具辅助下完成的」并标注工具信息；数据分析结果处加注释说明参考了 AI 输出
- [ ] 研赛：论文中的模型与公式均可溯源（正式文献或可查证网址）。**无推导过程、无引用标识、无法确认来源的 AI 生成模型与公式一律不予认可**
- [ ] 研赛：最终文字用参赛队自身语言表述，未直接粘贴 AI 生成段落
- [ ] 美赛：报告中内联引用并在参考文献列出所用 AI 工具，另附不计页数的 `Report on Use of AI`
- [ ] 美赛：已人工核验 AI 生成内容与引用的准确性
- [ ] 核心建模与分析由参赛队主导完成（不能把 AI 输出直接当核心成果）

## 三、国赛（CUMCM）专用

依据《论文格式规范（2026 年修订稿）》与《人工智能工具使用规定（2026 年试行）》。

### 红线
- [ ] 🔴 摘要页、正文、附录**任何位置**都没有参赛者身份、学校、赛区信息（含页眉页脚、文件名、文档属性）
- [ ] 🔴 附录含全部完整可运行源程序；若确未用程序，已写明"本论文没有用到程序"
- [ ] 🔴 支撑材料与论文内容相符（不符可能被取消资格），且其中也不含身份信息
- [ ] 🔴 电子版论文**第一页是摘要专用页**，承诺书与编号专用页**未**放入电子版
- [ ] 🔴 参考文献之前有「AI工具使用声明」（见第二节）
- [ ] 🔴 知网库与竞赛自建库**任一相似度 <25%**（≥25% 原则上不能报送全国评阅；赛区可能更严）

### 格式
- [ ] 纸质版：白色 A4，四边页边距 ≥2.5 cm，左侧装订
- [ ] 纸质版页码：第 1 页承诺书、第 2 页编号专用页、第 3 页摘要页
- [ ] 摘要（含标题与关键词）不超过一页；**不写英文摘要**（官方明确"无需翻译成英文"）
- [ ] 页码自摘要页起在页脚居中、阿拉伯数字连续编号
- [ ] 正文自第 4 页起，**不要目录**，**不超过 30 页**
- [ ] 附录在正文之后、页数不限，并与正文装订在一起提交
- [ ] 电子版与纸质版内容格式（含附录）完全一致
- [ ] 电子版为单个 PDF 或 Word 文件（建议 PDF），大小 ≤20 MB，未压缩
- [ ] 支撑材料打包为单个 RAR/ZIP，≤20 MB，且论文附录中含其**文件列表**
- [ ] 提交文件为"参赛论文 + 支撑材料"两个（按当年《报名和参赛须知》）
- [ ] 字体字号：**全国规范不作统一要求**，已向本赛区确认具体要求（勿照搬网上模板）
- [ ] 承诺书选题号（A/B/C/D/E）与作答题目一致
- [ ] 提交时序：竞赛结束（周日 20:00）前生成并提交 MD5 码，次日 14:00 前完成上传；**改文件会改变 MD5，需重新提交**

> 规范明确：不符合本规范的论文将被视为违反竞赛规则，可能被取消评奖资格。

## 四、研赛（华为杯）专用

依据《论文格式规范（2025，第二十二届）》与《人工智能工具及输出使用规定（2025）》。**每年细则可能修订，开赛前务必下载当年文件核对。**

### 红线
- [ ] 🔴 全文匿名：无身份标志、**无页眉**
- [ ] 🔴 附录含可运行源程序；按题目要求需上传的程序/结果已在规定时间内上传竞赛系统
- [ ] 🔴 AI 使用合规（见第二节），且模型与公式可溯源
- [ ] 🔴 引用书籍**已标注页码**；网上资源已注明访问时间

### 格式
- [ ] 论文题目、摘要、关键词均写在**摘要页**上；正文自摘要页的**下一页**开始
- [ ] 页码自摘要页开始，**位于每页页脚中部**，阿拉伯数字从 1 连续编号
- [ ] 排版：题目三号黑体；一级标题四号黑体并居中；其他汉字小四号宋体；单倍行距
- [ ] 摘要含六要素：**建模思路、主要方法、模型、结果与结论、创新点、关键词**；篇幅一般不超过两页；无需英文
- [ ] 参考文献格式符合官方给定样式（书籍/期刊/网上资源三种写法）
- [ ] 摘要与正文结论一致（官方明确"评阅时对摘要和论文都会审阅"）
- [ ] 赛程约 4 天，已留出至少 1 天给写作与检查
- [ ] 若题目要求提交特定格式的补充材料（数据表、程序包），已按要求命名与打包

## 五、美赛（MCM/ICM）专用

依据 COMAP 官方 Contest Rules, Registration and Instructions。

### 红线
- [ ] 🔴 **整份提交 ≤25 页**——Summary Sheet、正文、目录、参考文献、注释、**附录与代码**全部计入
- [ ] 🔴 姓名、导师、学校不出现在任何一页，只保留控制号
- [ ] 🔴 按当年规定披露 AI 使用并附 `Report on Use of AI`（不计页数）
- [ ] 🔴 单个 PDF、英文、字号至少 12 pt
- [ ] 🔴 每页页眉含控制号与页码（如 `Team # 0000000, Page 6 of 25`）
- [ ] 🔴 提交文件名 = 控制号.pdf，附件 <25 MB，且**不附带**程序/数据文件

### 结构与写作
- [ ] 第 1 页为 Summary Sheet（用官方模板），250–400 词，含量化结果
- [ ] Summary **最后写**，且不是题目复述或引言复制粘贴
- [ ] 有引入问题、变量与假设的清晰阐述，且**每条假设有论证**
- [ ] 有对所选模型的动因分析（为什么用它、为何不选替代方案）
- [ ] 每问都有 Model Development + Results
- [ ] 有独立的 Sensitivity Analysis（误差/灵敏度/稳定性）
- [ ] 有独立的 Strengths and Weaknesses（诚实、具体）
- [ ] 有面向决策者的 Conclusion，结论明确
- [ ] 冗长推导与数据放在附录，正文只留要点
- [ ] 目录（Table of Contents）可选但计入 25 页；已确认总页数
- [ ] 全英文写作，已检查语法与拼写（语言质量影响评级）
- [ ] 若题目要求 Memo / Letter / 一页非技术摘要，已按要求撰写
- [ ] 参考文献规范，所有外部来源（含网页）均已列出

---

## 六、提交前 30 分钟最终确认

1. 打开最终 PDF，**只读摘要**——如果 1 分钟内看不懂做了什么、得到什么，回去改摘要。
2. 搜索身份信息关键词（学校名、姓名、学号、队号、赛区、邮箱、手机号）。
3. 核对附录代码与论文数值是否一致（至少抽查 3 个关键数字）。
4. 确认页数（国赛正文 ≤30 页；美赛**全部** ≤25 页）、文件大小（国赛 ≤20 MB；美赛 <25 MB）、文件名符合要求。
5. 确认 AI 声明位置正确（国赛/研赛：参考文献之前）且表述与实际情况一致。
6. 确认所有提交文件都已上传/打印并装订，且**没有**把承诺书放进电子版。
