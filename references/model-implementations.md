# 增强模型库：题目类别、模型谱系与改进路线

> 覆盖数学建模竞赛中高频、可落地的模型族；不声称穷尽数学研究领域的全部模型。使用顺序：先判题目类别，再做透明基线，明确假设，选择改进，最后用匹配任务的验证方式证明有效。GitHub 代码只能作为实现参考，不能替代推导、数据审计和独立验证。

## 1. 总决策表

| 类别/题目动词 | 透明基线 | 常见改进 | 必须验证 |
|---|---|---|---|
| 资源分配、生产、排班、选址 | LP / MIP | 多目标、鲁棒/随机规划、分解、元启发式 | 可行性、松弛下界/gap、基线、敏感性 |
| 配送、路线、覆盖、网络流 | 最短路/指派/小规模 MIP | VRP 时间窗/容量、2-opt、ALNS、禁忌搜索 | 路径约束、成本、下界、运行时间 |
| 预测、趋势、预警 | 朴素法/均值/ARIMA | ETS、状态空间、XGBoost、LSTM、组合 | 滚动回测、MAE/RMSE、区间、基线 |
| 影响因素、显著性 | OLS / GLM | Ridge/Lasso、混合效应、稳健回归 | 残差、VIF、置信区间、交叉验证、泄漏 |
| 分类、识别、异常 | 逻辑回归/决策树 | SVM、随机森林、梯度提升、校准 | 分层 CV、混淆矩阵、F1/AUC、独立测试 |
| 综合评价、排序、选优 | 标准化+等权 | AHP/熵权、TOPSIS、VIKOR、DEA、模糊评价 | 权重来源、AHP CR、扰动、Spearman/Kendall |
| 传播、生长、衰减、库存 | ODE/差分 | Logistic、SIR/SEIR、状态空间、控制 | 拟合残差、步长收敛、平衡点、灵敏度 |
| 热传导、扩散、流体、场 | 守恒方程+有限差分 | 有限元、隐式格式、无量纲化、反问题 | 边界/初值、网格收敛、量纲、守恒误差 |
| 风险、命中概率、不确定性 | 蒙特卡洛 | LHS、方差缩减、重要抽样、场景分析 | 种子、样本量、标准误、CI、收敛曲线 |
| 排队、服务台、拥堵 | M/M/1 或 M/M/c | 非齐次到达、优先级、离散事件仿真 | ρ<1、等待时间、独立重复、仿真区间 |
| 路径、连通、关键节点 | Dijkstra/BFS | k-shortest、最大流、中心性、社区、鲁棒攻击 | 复杂度、容量、删点删边压力测试 |
| 几何、覆盖、测线、定位 | 坐标几何+数值优化 | Voronoi、可见域、非线性最小二乘 | 极限情形、几何误差、单位、可行域 |
| 竞争、策略、博弈 | 规则模型/静态博弈 | Stackelberg、演化博弈、最优控制、ABM | 均衡稳定、扰动、策略解释性 |
| 图像、遥感、缺陷检测 | 阈值/形态学/PCA | SVM、CNN、分割、检测 | 标注协议、IoU/F1、跨场景、误检漏检 |
| 多问递进综合题 | 每问透明基线 | 机理+数据、预测+优化、评价+分类 | 接口一致、误差传播、共享参数 |

## 2. 优化与运筹

### 2.1 LP / IP / MIP

**信号**：安排、分配、选址、采购、生产、投资、排班；变量是数量或“是否选择”。骨架是决策变量 `x`、目标 `min/max cᵀx`、约束 `Ax≤b`/`A_eqx=b_eq` 与整数/二元域。LP 可用 `scipy.optimize.linprog`；MIP 可用 PuLP、OR-Tools、Gurobi、CPLEX 或 LINGO。

**改进阶梯**：LP 加整数约束修复“半个人”；单目标改 ε-约束或 Pareto；确定参数改场景/鲁棒/机会约束；大规模精确求解加松弛下界、warm start 或分解。论文须解释每组约束的现实含义，报告求解状态、可行性、gap/下界，并与现状或贪心基线比较。禁止把可行解称全局最优。

### 2.2 路径、车辆路径与调度

| 结构 | 基线 | 增强 |
|---|---|---|
| 单源最短路 | Dijkstra（非负边） | A*、时间依赖边权、k-shortest |
| 多点访问 | 小规模 TSP 精确 MIP | 2-opt/3-opt、蚁群、遗传、ALNS |
| 配送 | CVRP | 时间窗 VRPTW、容量/多仓/软约束 |
| 工序安排 | 最早截止期/贪心 | MIP、CP-SAT、遗传/禁忌搜索 |

必须程序化回放容量、时间窗、访问次数和回路闭合。启发式只能说“在此实例上更好”，不能声称全局最优。

### 2.3 多目标、鲁棒与随机规划

加权和适合偏好已知且尺度统一；ε-约束更易解释；NSGA-II 要报告种群、迭代和停止标准。鲁棒优化通常更稳健但更保守；随机规划需要数据或明确分布支持场景概率。应同时报告 nominal、最坏和平均场景。

## 3. 预测与统计学习

### 3.1 时间序列

推荐阶梯：季节朴素法 → ARIMA/SARIMA 或 ETS → 特征回归/XGBoost → LSTM/Transformer（只有样本支持时）。ARIMA 要差分、ACF/PACF、AIC/BIC、白噪声残差；ETS 适合趋势/季节明显的短序列；GM(1,1) 适合小样本近似指数趋势，需报告后验差比 C 与小误差概率 P；卡尔曼要区分过程噪声和观测噪声；组合权重不能用测试集调参。

**硬性验证**：rolling-origin 回测，按 horizon 报 MAE/RMSE；真值近零时避免 MAPE；给预测区间；和上一期值/季节朴素法比较。时间序列不能随机打乱切分。

### 3.2 回归、分类、聚类、降维

回归可按 OLS → Ridge/Lasso → GLM → 混合效应 → 稳健回归升级；逻辑回归是可解释分类基线，树集成处理非线性，SVM 适合中小样本；K-means 假定球状簇，DBSCAN 适合噪声/任意形状，GMM 提供软归属；PCA 前要标准化并报告解释方差和载荷。改进必须用嵌套 CV/时间切分、残差诊断、校准、泄漏审计和可解释性证明。

## 4. 评价、决策与风险

- **AHP**：专家判断驱动；报告判断矩阵来源、最大特征值与 `CR<0.1`（若采用该阈值）。
- **熵权**：数据驱动；写清正/负向指标、标准化和零值处理，做删样本/Bootstrap 敏感性。
- **TOPSIS**：理想解距离排序；方向、权重和距离度量会影响结果，可与 VIKOR 比较。
- **DEA**：多投入多产出；检查样本量与指标冗余。若未找到可核验的专用仓库，可用成熟优化器自行写 CCR/BCC 线性规划，并说明这一点。
- **模糊综合评价**：适合优/良/中/差等模糊等级；隶属函数不能凭空设置。
- **蒙特卡洛**：明确分布、样本量、标准误/置信区间、种子和收敛曲线。
- **排队**：M/M/1、M/M/c 需检查到达/服务假设和稳态 `ρ<1`；复杂系统用离散事件仿真并做独立重复。
- **马尔可夫链**：状态、转移矩阵来源、遍历/吸收条件和稳态推导完整。

评价类统一协议：至少一种权重扰动 + 一种替代排序方法 + Spearman/Kendall 一致性；不稳健时报告不确定性。

## 5. 机理、动力学、几何与空间

### 5.1 ODE/PDE/差分

顺序为：状态变量 → 守恒/变化率 → 初值/边界 → 参数来源 → 数值求解 → 稳定性与灵敏度。Logistic 用于资源受限增长；SIR/SEIR 按潜伏期、免疫和年龄层决定复杂度；反应/库存/种群 ODE 可用 `solve_ivp`；扩散/热传导 PDE 用有限差分/有限元并做网格收敛；差分/元胞自动机须公开邻域、更新顺序、边界和随机种子。改进路线是无量纲化 → 解析/数值对照 → 数据校准 → 参数/结构敏感性 → 控制/优化。

### 5.2 几何、定位、覆盖与物理

定位可用三边测量、最小二乘、非线性最小二乘；覆盖/测线可用坐标几何、可见域、Voronoi、集合覆盖/MIP；物理题先画受力/控制体，写质量、动量、能量守恒，再加入损耗和边界。验证要包含极限情形、单位、守恒残差、实测误差与坐标系说明。

## 6. 网络、博弈、图像与综合题

- **网络**：Dijkstra/最大流/匹配做透明基线，再按规模加入 VRP、中心性、社区发现或鲁棒攻击；报告稀疏性和复杂度。
- **博弈**：说明参与者、策略、收益和信息结构；需要时用 Stackelberg、演化博弈或 ABM；验证均衡稳定性。
- **图像**：阈值/形态学/PCA 是可解释基线，再考虑 SVM/CNN；报告标注协议、IoU/F1、跨场景测试和误检漏检。
- **多问综合**：定义各问输入输出接口、共享参数与误差传播，避免前问预测误差被后问放大而未说明。

## 7. GitHub 代码使用规范

1. 先读 README 和许可证；GPL/AGPL 代码不能不加处理地并入 MIT 项目。
2. 记录仓库、路径、许可证、访问日期和 commit SHA；不要只记录会漂移的 `main` 链接。
3. 只借实现，不借结论：重跑示例，记录输入、参数、种子、版本与验证。
4. 优先透明基线；算法多不代表适合本题。
5. 不运行来源不明的二进制或安装脚本；锁定依赖与运行环境。
