## 1. 优化与规划

**适用信号**：题目出现决策变量、资源约束、目标函数（成本/收益/时间/覆盖率）。

| 方法 | 适用条件 | 工具 |
|---|---|---|
| 线性规划 (LP) | 目标与约束均线性、变量连续 | `scipy.optimize.linprog`、LINGO、Gurobi |
| 整数/0-1 规划 (IP/MIP) | 离散决策（选或不选、台数） | PuLP、OR-Tools、Gurobi、LINGO |
| 非线性规划 (NLP) | 目标含乘积/指数/三角 | `scipy.optimize.minimize`、IPOPT |
| 多目标规划 | 多个冲突目标 | 加权和、ε-约束、NSGA-II（`pymoo`） |
| 动态规划 | 阶段可分、无后效性 | 手写状态转移，注意状态维度爆炸 |
| 鲁棒/随机规划 | 参数不确定 | 场景法、机会约束 |
| 启发式/元启发式 | NP-hard、规模大、无解析梯度 | 遗传算法（`geatpy`/DEAP）、模拟退火、粒子群、蚁群 |
| 背包/指派/排班 | 经典组合结构 | 转化为 MIP 后用求解器，别自己写搜索 |

**必做**：
1. **写清三要素**：决策变量、目标函数、约束条件——论文里要有数学表达式，不能只有文字。
2. **给可行性与最优性证据**：至少报告约束是否全部满足；能用求解器就报告 gap / 对偶信息。
3. **基线对比**：贪心解、现状方案、或松弛下界。只报"我们的算法得到 X"没有说服力。
4. **启发式必做收敛性/重复实验**：多次独立运行给均值±标准差，否则结果不可信。

**陷阱**：把连续变量硬当整数；忘记非负约束；多目标只用加权和却不做权重敏感性；用启发式但声称"最优"。

## 2. 微分/差分方程与动力学

**适用信号**：传播、生长、衰减、温度、浓度、种群、传染病、舆情、能耗演化。

- **建模步骤**：定义状态变量 → 写守恒/变化率关系 → 定初值与边界 → 无量纲化 → 求解析或数值解 → 稳定性/平衡点分析。
- **常用形式**：一阶 ODE（指数增长/衰减）、Logistic、Lotka-Volterra（捕食）、SIR/SEIR（传染病）、热传导/扩散（PDE）、差分方程（离散时段）。
- **数值方法**：`scipy.integrate.solve_ivp`（RK45）、显式/隐式欧拉、有限差分（PDE）；MATLAB `ode45`。
- **必做**：参数拟合要有数据支撑并给置信区间；灵敏度分析（基本再生数 R₀ 类指标）；数值解与解析解（若有）对比；步长收敛性检验（步长减半结果不变）。
- **元胞自动机**：适合局部规则驱动的时空演化（交通流、森林火灾、疏散）；必须说明邻域、规则、边界与随机性种子，并做多次仿真取统计量。
- **陷阱**：未做无量纲化导致参数不可解释；PDE 未给边界条件；只画一条曲线不给参数范围。

## 3. 统计与回归

**适用信号**：找影响因素、解释变量关系、检验显著性、数据降维与分组。

| 任务 | 方法 | 工具 |
|---|---|---|
| 连续因变量 | 多元线性回归、岭回归/Lasso、广义线性模型 | `statsmodels`、`sklearn.linear_model` |
| 计数/比例 | 泊松/负二项、Logistic | `statsmodels` |
| 面板/分层数据 | 混合效应模型 | `statsmodels` MixedLM、R lme4 |
| 降维 | 主成分分析 (PCA)、因子分析 | `sklearn.decomposition` |
| 分组 | K-means、层次聚类、DBSCAN、GMM | `sklearn.cluster` |
| 判别 | 判别分析、SVM、树集成 | `sklearn` |

**必做**：多重共线性检查（VIF）、残差诊断（正态性/异方差/自相关）、交叉验证、显著性水平与置信区间报告。
**陷阱**：把相关当因果；用 R² 当唯一指标（应同时看调整 R²、RMSE、残差图）；特征泄漏（用未来信息预测过去）；不报告样本量与数据处理过程。

## 4. 时间序列与预测

- **ARIMA/SARIMA**：平稳性检验（ADF）→ 定阶（ACF/PACF、AIC/BIC）→ 残差白噪声检验 → 滚动预测。
- **指数平滑 (Holt-Winters)**：有趋势/季节性且序列较短时的稳健选择。
- **灰色预测 GM(1,1)**：样本极少（≥4）且近似指数增长；必须做**后验差比检验**（C 值、小误差概率 P）。
- **卡尔曼滤波**：带噪声的动态系统状态估计，适合实时更新。
- **机器学习**：LSTM/Transformer/梯度提升，适合多变量、大数据；需要构造滞后特征。
- **组合预测**：不同模型的加权/平均常优于单一模型——给权重确定方法与对比表。

**必做**：**滚动回测**（rolling-origin），报告 MAE/RMSE/MAPE，并与朴素基线（上一期值、均值）对比——不打败朴素基线的预测模型没有价值。
**陷阱**：在全体数据上定阶再在同一数据上评估（乐观偏差）；忽略季节性；MAPE 在接近 0 的序列上爆炸（改用 MAE）；只给一条预测曲线不给区间。

## 5. 评价与决策

**适用信号**："综合评价""排序""选优""绩效""等级划分"。

- **AHP（层次分析法）**：指标少、需专家判断；必须做**一致性检验 CR < 0.1**，并说明判断矩阵来源。
- **熵权法**：数据驱动定权；要求指标可量化。注意正向/负向（极差标准化）与零值处理。
- **TOPSIS**：贴近度排序，常与熵权/AHP 组合（组合赋权）。
- **模糊综合评价**：指标含"好/中/差"等定性等级时。
- **DEA**：多投入多产出效率评价。
- **灰色关联分析**：小样本、信息不完全时的关联度排序。
- **秩和比 / VIKOR / PROMETHEE**：排序稳健性互补方法。

**必做（这是评价类题目的得分核心）**：
1. 指标体系的**来源依据**（文献、标准、题目要求），不要凭空列指标。
2. 标准化方法与权重方法写清楚，给出权重表。
3. **权重敏感性分析**：扰动权重（±10%/±20%）看排序是否变化；给出排序稳定性结论。
4. **多方法交叉验证**：用两种以上方法排序并比较一致性（如 Spearman 秩相关），一致则结论可信，不一致要解释。

**陷阱**：只用一种主观赋权法；不一致性检验缺失；把不同量纲指标直接加权；排序结论远超数据支持的精度。

## 6. 图论与网络

- **基础**：最短路（Dijkstra/Floyd）、最小生成树（Prim/Kruskal）、最大流/最小费用流、二分图匹配。
- **路径规划**：TSP（小规模精确、大规模启发式/2-opt）、VRP（容量/时间窗）、A*/D*（栅格地图）。
- **网络分析**：度/介数/接近中心性、连通性、鲁棒性（去点/去边攻击）、社区发现（Louvain）、PageRank。
- **工具**：`networkx`、`igraph`、OR-Tools、MATLAB `graph`/`shortestpath`。

**必做**：网络规模与稀疏性说明；算法复杂度或运行时间；结果可视化（节点/边、路径高亮）；鲁棒性或敏感性（删掉关键节点会怎样）。
**陷阱**：大图用 Floyd（O(n³)）不自知；把启发式路径当最优；忽略方向性与权重含义。

## 7. 随机建模与仿真

- **蒙特卡洛**：积分/概率/风险估计。必须报告**样本量与标准误**、收敛曲线、随机种子（可复现）。
- **排队论**：M/M/1、M/M/c、M/G/1；给出到达率 λ、服务率 μ、利用率 ρ、平均队长与等待时间；检验稳态假设（ρ<1）。
- **马尔可夫链**：状态转移矩阵、稳态分布、吸收概率；转移概率要有估计依据。
- **离散事件仿真**：`simpy` / Simulink / AnyLogic 思路；仿真次数与置信区间是硬要求。
- **陷阱**：只跑一次仿真就下结论；用伪随机但不设种子；把仿真当"证明"（它是估计，要给误差）。

## 8. 机器学习与数据驱动

- **流程**：数据清洗 → 特征工程 → 划分训练/验证/测试 → 基线模型 → 调参 → 交叉验证 → 误差分析 → 解释性。
- **模型选择**：先线性/树模型建立基线，再考虑神经网络；小样本优先简单模型。
- **必做**：防泄漏（时间序列按时间切分）、类别不平衡处理（重采样/类权重/合适指标如 F1、AUC）、特征重要性解释（SHAP/置换重要性）、计算成本说明。
- **陷阱**：拿测试集调参；只报准确率（不平衡数据下无意义）；黑箱模型不做任何解释；数据不足仍硬上深度学习。

---

## 9. 几何、物理与量纲

- **几何概型/坐标法**：定位、覆盖、投影、长度面积体积最优化。
- **物理守恒**：质量/动量/能量守恒；受力分析图必画。
- **量纲分析 / 无量纲化**：减少参数个数（Buckingham π 定理），提升可解释性与数值稳定性。
- **比例缩放**：小试到中试、模型到原型。
- **陷阱**：单位不统一（秒/分钟/小时混用）；方程两边量纲不一致；忽略摩擦/损耗等被题目隐含的条件。

---

## 10. 组合与混合建模（多问型赛题常用）

- **预测 + 优化**：先预测需求/参数，再在预测上做决策；必须处理**预测不确定性**（场景/区间优化），否则"最优"很脆弱。
- **机理 + 数据**：机理定结构，数据定参数（灰箱模型），比纯黑箱更可解释、比纯机理更贴合实际。
- **评价 + 分类**：先降维/聚类分组，再对每组给策略。
- **多问递进**：后续问应在前面模型上**升级或复用**，并在论文中显式说明"本问沿用了问题二的模型，改动为…"——不要每问换一套互不相干的模型。

## 12. 反模式总表（出现即扣分）

1. **模型堆砌**：把 AHP+熵权+TOPSIS+神经网络全用上，但不解释为什么需要、各模型解决哪一问。
2. **无检验**：只给结果，没有误差、灵敏度、稳健性、对比基线。
3. **数据来路不明**：用了外部数据却不给来源与预处理过程。
4. **不可复现**：附录没有可运行代码，或代码与论文结果不一致（国赛可能直接取消资格）。
5. **假设不落地**：假设写了但后续建模中从未使用或从未说明其影响。
6. **符号混乱**：同一符号两种含义，或正文与符号表不一致。
7. **过度精确**：给出与数据精度不匹配的有效数字（如用 3 位有效数字的数据报 8 位结果）。
8. **结论超出模型**：把特定参数下的仿真结论推广成普适规律。
