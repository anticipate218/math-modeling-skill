# 优秀论文的查找、阅读与"配图"规范

> **本文件刻意不包含任何他人论文的图片或截图。**
> 本仓库的配图全部是脚本自己生成的（见 `assets/gallery/`，由 `scripts/make_figures.py` 生成），
> 原因是版权与学术诚信，不是偷懒。下面第 1 节说明理由，第 2 节给出**合法**的检索入口，
> 第 3 节按题目类型告诉你"该看优秀论文的哪一部分、该自己画哪张图"。

## 1. 为什么不能把优秀论文的图搬进仓库（和你的论文）

必须区分两件事：

| 行为 | 是否可用 | 说明 |
|---|---|---|
| 在论文里**引用**某篇优秀论文的观点、方法，并在参考文献里列出 | ✅ 可以 | 这是正常学术行为 |
| 在论文里**复现**某篇论文的方法，用自己生成的数据画出**自己的**图 | ✅ 可以 | 这是本仓库 `assets/gallery/` 走的路 |
| 把他人论文里的图**截图/下载**后放进自己的论文正文 | ⚠️ 通常不行 | 属于复制他人作品，需获得授权（COMAP 的 `Permissions/Use` 页面对此有专门规定），多数竞赛的诚信条款也会认定为不当引用 |
| 把他人论文的图**打包进公开仓库**再分发 | ❌ 不行 | 比上一条更严重：这是向不特定公众再分发受版权保护的作品 |

三条现实约束：

1. **版权**：竞赛论文的著作权归**作者本人**（不是主办方）。主办方把它们放到官网，是"发布"，不是"放弃版权"。
   即使某份 PDF 可以自由下载，也不等于可以再分发其中的图片。
2. **竞赛诚信**：国赛和美赛都把"抄袭/不当引用"列为取消评奖资格的事由。把别人的图当自己的图用，
   风险远大于收益。
3. **仓库性质**：本仓库是一个**公开的、会被别人 clone 的** Agent Skill。在仓库里放他人论文图片，
   等于替所有使用者承担侵权风险。本仓库选择不这么做。

**正确做法**：把优秀论文当"范文"读结构、读论证链条、读图表设计思路，然后
①用自己的数据 ②用自己的代码 ③画自己的图。`scripts/make_figures.py` 就是为此准备的
现成起点——它生成的 16 张图覆盖了各题目类型最常需要的那几张图。

## 3. 按题目类型：优秀论文看什么 + 自己该画哪张图

这一节是"读范文"的操作清单。**"看什么"列的是阅读重点，"自己画什么"列的是你论文里必须有的图，
两者都不是让你去复制图片。**

### 3.1 优化 / 调度类（MCM B、ICM D、国赛 B 题常客）

| 看什么 | 自己画什么 | 现成实现 |
|---|---|---|
| 决策变量与约束是怎么从**自然语言题面**翻译成数学符号的（这是最值得学的一段，比模型本身重要） | 收敛/迭代曲线：目标函数值 vs 迭代次数，证明你的算法确实在收敛 | `assets/gallery/optimization_convergence.png` |
| 目标函数怎么写、多个目标怎么处理（加权？ε-约束？分层？） | Pareto 前沿散点图：两个冲突目标下的非支配解集 | `assets/gallery/optimization_pareto.png` |
| 约束的**紧松性**分析：哪些约束在最优解处取等号 | 约束活跃性热力图或可行性区域示意 | `examples/algorithms/optimization.py` |
| 灵敏度分析怎么写（某个参数 ±20% 时最优解怎么变） | 参数扫描曲线（一图多线） | `examples/modeling_patterns.py` |

**读范文的陷阱**：很多优秀论文用了商业求解器（Gurobi/CPLEX）却只写"用 Lingo 求解"，看不出模型本身。
重点读**模型部分**，不要被求解器名字带偏。

### 3.2 预测 / 时间序列类（MCM C、国赛 C 题）

| 看什么 | 自己画什么 | 现成实现 |
|---|---|---|
| 数据预处理写了多少（缺失、异常、季节性、量纲）——好论文在这块通常占一整节 | 原始序列 + 趋势/季节分解图 | `assets/gallery/forecast_models_compare.png` |
| 为什么要选这个模型：有没有做**模型比较**而不是只报一个模型的误差 | 多模型预测对比图（含真实值） | `forecasting.py` |
| 误差指标是否报了多个（MAPE 遇到 0 会失效，见 `forecasting.py` 的陷阱） | 残差诊断四联图（时序、ACF、QQ、直方图） | `assets/gallery/forecast_residual_diagnostics.png` |
| **验证方式**：是不是按时间顺序切分？有没有滚动原点交叉验证？ | 滚动预测的误差随预测步长变化曲线 | `examples/algorithms/forecasting.py` |

**读范文的陷阱**：只报 MAPE 不报置信区间的预测论文，结论通常是不可用的。

### 3.3 评价 / 决策类（ICM E、国赛 C/D 题、各类"综合排名"题）

| 看什么 | 自己画什么 | 现成实现 |
|---|---|---|
| **指标体系的构建逻辑**：为什么是这几个指标、数据从哪来、量纲怎么处理 | 权重条形图 + 权重来源对比 | `assets/gallery/evaluation_weights.png` |
| 权重是怎么定的：主观（AHP）？客观（熵权/CRITIC）？还是组合？有没有说明理由 | 各方案得分的雷达图 | `assets/gallery/decision_radar.png` |
| 有没有做**灵敏度分析**：权重扰动后排名会不会翻——这是区分好坏论文的关键一节 | 权重扰动下的排名变化图 | `assets/gallery/evaluation_weights_sensitivity.png` |
| 有没有对多个评价方法做**一致性检验**（TOPSIS 与 VIKOR 结论是否一致） | 排序对比图（多方法 × 多方案） | `assets/gallery/evaluation_topsis_rank.png` |

**读范文的陷阱**：AHP 判断矩阵不做一致性检验（CR > 0.1 还用）是高频错误；
熵权法直接套用而不做正向化，会把成本型指标算反。

### 3.4 机理 / 微分方程类（MCM A、国赛 A 题）

| 看什么 | 自己画什么 | 现成实现 |
|---|---|---|
| **假设是怎么提的**：每条假设对应模型里哪一项，假设不成立时结论怎么变 | 机理模型的核心状态量时序图 | `assets/gallery/mechanism_sir.png` |
| 参数是怎么估计的（拟合？文献？反问题？），有没有给区间 | 单参数扫描 + 多参数热力图 | `assets/gallery/mechanism_param_sensitivity.png` |
| 量纲是否一致、各项物理意义是否清楚 | 相图 / 场图 | `examples/algorithms/differential.py` |
| 数值方法的稳定性与步长选择（显式欧拉在大刚度问题上会炸） | 不同步长下的解对比图 | `differential.py` 的陷阱小节 |

**读范文的陷阱**：只给一条曲线不给参数区间的机理模型，无法判断稳健性。

### 3.5 仿真 / 随机类（ICM D/E、排队与蒙特卡洛题）

| 看什么 | 自己画什么 | 现成实现 |
|---|---|---|
| 随机变量的分布假设从哪来，有没有做拟合优度检验 | 蒙特卡洛收敛图（估计值 ± 置信带 vs 样本量） | `assets/gallery/simulation_mc_convergence.png` |
| 重复次数够不够，有没有报标准误 | 排队系统的队长/等待时间分布图 | `assets/gallery/simulation_queueing.png` |
| 随机数种子是否固定、结果是否可复现 | 多次独立重复的结果箱线图 | `examples/algorithms/stochastic.py` |

### 3.6 分类 / 聚类 / 降维类（MCM C、数据挖掘题）

| 看什么 | 自己画什么 | 现成实现 |
|---|---|---|
| 特征工程做了哪些处理，为什么 | 聚类结果散点图（含簇心） | `assets/gallery/clustering_result.png` |
| 聚类数 K 是怎么定的（肘部法？轮廓系数？业务解释？）——三种都要看 | 肘部图 / 轮廓系数 vs K | `clustering.py` |
| 有没有交叉验证，评价指标是否与题目目标一致 | 混淆矩阵或 ROC 曲线 | `examples/algorithms/clustering.py` |

### 3.7 图论 / 网络类（ICM D、路径与网络题）

| 看什么 | 自己画什么 | 现成实现 |
|---|---|---|
| 网络是怎么建的：节点、边、权重的定义依据 | 网络结构图（节点按中心性着色） | `assets/gallery/graph_shortest_path.png` |
| 用了哪些中心性指标，指标之间是否冗余 | 中心性指标对比条形图 | `examples/algorithms/graphs.py` |
| 路径/流问题的约束是否被正确表达 | 最短路/最小生成树高亮图 | `graphs.py` |

### 3.8 博弈 / 多主体类（ICM F、政策类题目）

| 看什么 | 自己画什么 | 现成实现 |
|---|---|---|
| 参与者、策略集、收益函数分别是什么，信息结构是静态还是动态 | 收益矩阵热力图 | `examples/algorithms/game.py` |
| 均衡的存在性与唯一性有没有讨论 | 最优反应曲线 / 演化博弈相图 | `game.py` |
| ABM 的规则是否可解释，有没有做规则敏感性分析 | 主体状态演化时序图 | `examples/algorithms/stochastic.py` |

### 3.9 空间 / 几何类（含 GIS 的题目）

| 看什么 | 自己画什么 | 现成实现 |
|---|---|---|
| 坐标系与距离度量（欧氏？曼哈顿？大圆？）的选择依据 | 空间插值等值线图 | `assets/gallery/spatial_interpolation.png` |
| 插值/拟合方法的交叉验证误差 | 留一交叉验证误差分布图 | `examples/algorithms/geometry.py` |

### 3.10 统计推断 / 相关性类（数据洞察题的基础章节）

| 看什么 | 自己画什么 | 现成实现 |
|---|---|---|
| 相关 ≠ 因果是否被明确写出；有没有控制混杂变量 | 相关系数矩阵热力图 | `assets/gallery/statistics_correlation.png` |
| 假设检验的前提（正态性、方差齐性）是否被检验过 | 残差图 / QQ 图 | `examples/algorithms/statistics.py` |
| p 值之外有没有报**效应量**和置信区间 | 系数森林图（估计值 ± 置信区间） | `statistics.py` |

## 4. 想引用某张图时，怎么做才合规

1. **优先自己画**。本仓库的 16 张图 + 各算法模块已经覆盖了绝大多数场景。
2. 确实需要引用他人图时：**取得许可**（许多作者和期刊对教学用途会同意，但必须问）；
   并在图注中写明"引自 [文献]，已获得许可/依 CC BY 4.0 使用"。
3. 使用**开放许可**素材时，核对许可证类型（CC BY / CC BY-SA / CC0 的要求不同），
   并在仓库/论文中保留署名与许可证链接。
4. 引用数据而非图片时，同样要在参考文献和数据可用性声明中写清来源与访问日期。
5. 美赛参赛者特别提示：先用 <https://comap.org/permissions-use> 确认 COMAP 材料的使用范围。
